# Security Policy

## Supported versions

Security fixes are made for the latest published plugin version. Users should
update both Jellyfin and Content Requests to supported releases.

## Reporting a vulnerability

Please do not publish vulnerabilities, credentials, server addresses, request
contents, or other private deployment data in a public issue.

Use GitHub's **Security** tab and select **Report a vulnerability** to send a
private report. Include the plugin version, Jellyfin version, reproduction
steps, impact, and any relevant sanitized logs. If private vulnerability
reporting is unavailable, open a public issue containing no sensitive details
and ask the maintainer for a private contact method.

You should receive an initial acknowledgement within seven days. Disclosure
timing will be coordinated after the report has been assessed and a fix is
available.
